# Demo de Summa

1. Abrir `/auth/login`. Para mostrar onboarding elegir **Crear mi hogar demo**, avanzar los cinco pasos y aceptar privacidad. Para un historial completo, cerrar sesión y elegir **Conocer el Hogar Medina**.
2. En Inicio revisar **Hoy puedes gastar**, próximos pagos, colchón y temporada.
3. Perfil → autorizar importación → **Conectar Banco de prueba**. Esperar un momento y recargar. La conexión queda activa y en Pagos fijos aparece una tarjeta con **$2,100 para no generar intereses**, vencimiento dentro de cinco días.
4. Movimientos → Ticket → **Probar con ejemplo simulado** → revisar monto/categoría → **Sí, guardar**. Sin API no se afirma haber leído una foto real. Con Gemini, activar consentimiento y subir imagen previamente depurada.
5. Voz → dictar o escribir **ayer gasté 150 en gasolina** → analizar → confirmar. También funcionan **85 de tacos y 40 del camión** y **me cayó la quincena, 6 mil**.
6. Mandado → revisar productos sugeridos, editar la lista compartida y comparar precios. Los precios ficticios indican **DEMO** y los de tickets indican su fecha.
7. Abrir el círculo coral → **¿Me alcanza para el regreso a clases?**. Ver el apartado semanal calculado y el presupuesto diario. Reportes permite inspeccionar categorías y periodos.
8. Perfil → **Forzar fallo** de Syncfy → crear una nueva conexión. Debe seleccionarse Finerio **simulado**. La conexión anterior mantiene Syncfy y conserva sus movimientos. Restaurar el proveedor al terminar.
9. Mostrar la descarga personal, QR del hogar y controles de privacidad.

La demo no mueve dinero, no pide contraseñas bancarias y no usa instituciones bancarias reales. Las fechas de los fixtures se adaptan a la fecha de ejecución; los montos y las etiquetas son ejemplos.
